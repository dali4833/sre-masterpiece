# 🚀 SRE Masterpiece – Multi-Cloud Platform

## 🎯 Project Overview
Building a production-grade, multi-cloud SRE platform with:
- **AWS EKS** + **Azure AKS** + **GCP GKE**
- **GitOps** with ArgoCD
- **Observability** with Prometheus + Grafana + Loki + Tempo
- **Service Mesh** with Istio
- **Security** with Trivy + Vault + OPA
- **Chaos Engineering** with Chaos Mesh
